# Hayat Abdurehman - Portfolio

A responsive personal portfolio introducing Hayat Abdurehman, a Software Engineering student and frontend developer. It includes an introduction, skills, featured projects, and contact links.

## Features

- Responsive layout for mobile and desktop
- Smooth scrolling between page sections
- Mobile navigation menu that opens on hover
- Profile image and featured project links

## Built with

- HTML
- CSS
- Tailwind CSS via CDN
- Font Awesome and Devicon icon fonts via CDN

## Run locally

Open `index.html` in a browser. The external stylesheets and icons are loaded from CDNs, so an internet connection is needed for those assets.

Alternatively, from the project directory, start a local server with Python:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).
